#  ⚡ NeuralDecide: AI Decision Intelligence System

# Here is the link of this project - https://ai-decision-analysis.vercel.app/

# NeuralDecide is a hackathon MVP web app that turns a plain-text problem description into a structured analysis. Describe your problem, and the app detects its domain, predicts the likely outcome, rates the difficulty, and suggests practical solutions.

# 

# \## ✨ Features

# 

# \- Plain-language problem input (up to 500 characters) with a live character counter

# \- Automatic domain detection and sentiment analysis

# \- Difficulty scoring and outcome prediction with a confidence level

# \- Domain-specific, actionable solution suggestions

# \- One-click example problems (team productivity, app crashes, declining sales, security breach, learning a new skill)

# \- Animated "AI Engine Processing" steps

# \- Recent Analyses history that can be reloaded

# \- Responsive dark UI

# 

# \## 🛠️ Tech Stack

# 

# \- \*\*HTML5\*\*: page structure

# \- \*\*CSS3\*\*: dark theme, animations, layout

# \- \*\*Vanilla JavaScript\*\*: analysis logic, no frameworks or backend

# \- \*\*Google Fonts\*\*: Syne and DM Mono

# 

# \## 🧠 How It Works

# 

# 1\. Enter a problem, or pick an example chip.

# 2\. Click \*\*Analyze \& Predict\*\*.

# 3\. The app parses the text, classifies the domain, scores sentiment and difficulty, and generates a prediction and solutions.

# 4\. Results appear on screen and are saved to the history list.

# 

# \## ⚠️ Note

# 

# This MVP uses keyword-based and rule-based logic in JavaScript to simulate AI analysis. It does not call a live AI model. It is designed so a real AI API can be plugged in later.
